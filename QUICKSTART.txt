CUSTOMIZATION TIPS
==================

COLORS:
- Edit assets/sass/libs/_vars.scss for color variables
- Main brand color, accents, backgrounds, text colors

FONTS:
- Typography files in assets/sass/base/
- Main fonts are already optimized and embedded

SPACING & LAYOUT:
- Modify assets/sass/libs/_mixins.scss for responsive breakpoints
- Grid system in assets/css/main.css

ADDING NEW PAGES:
- Copy structure from existing HTML files
- Keep same header, menu, and footer
- Update page title and content
- Add to navigation menu on all pages

REMOVING PAGES:
- Delete HTML files
- Remove from navigation menu in all pages
- Update any internal links

DESIGN CHANGES:
- Don't modify HTML if you only want style changes
- Edit CSS and SASS files instead
- Compile SASS if you make changes

TROUBLESHOOTING
================

Q: Images not showing?
A: Ensure image files are in assets/images/ with correct filenames
   Check image src paths in HTML match the actual filenames

Q: Styles not applying?
A: Check CSS files are linked correctly in <head>
   Clear browser cache (Ctrl+F5 or Cmd+Shift+R)
   Check browser console for CSS errors

Q: Contact form not working?
A: Form is set up structurally but needs backend configuration
   Update form action attribute to your form handler URL
   See step 3 in "IMMEDIATE NEXT STEPS" above

Q: Navigation not working?
A: Verify all HTML files are in the root directory
   Check file names match exactly (case-sensitive)
   Verify href links point to correct filenames

Q: Not responsive on mobile?
A: This template is mobile-responsive by default
   Check viewport meta tag is in <head>
   Clear browser cache
   Test in different browser if needed
