INTERNAL LINKS
==============

From INDEX.html (Homepage):
- Main Logo → index.html (stays on page)
- "Our Services" button → services.html
- Service tiles → services.html#serviceName
- "Learn More" button → about.html
- Contact section → contact.html
- Menu links → various pages
- Footer links → same pages

From ABOUT.html:
- Logo → index.html
- Menu → all pages
- "Contact Us" button → contact.html
- "View Our Services" button → services.html
- Footer links → all pages

From SERVICES.html:
- Logo → index.html
- Menu → all pages
- Service anchor links → services.html#ocean/air/customs/warehouse/docs/consult
- "Request a Quote" button → contact.html
- Footer links → all pages

From CONTACT.html:
- Logo → index.html
- Menu → all pages
- All form submit → form handler
- Footer links → all pages

FORM FIELDS & VALIDATION
========================

Contact Form Fields:
1. Full Name
   - Type: Text input
   - Required: Yes
   - Validation: Text only

2. Email
   - Type: Email input
   - Required: Yes
   - Validation: Valid email format

3. Company
   - Type: Text input
   - Required: No
   - Validation: Text only

4. Phone
   - Type: Tel input
   - Required: No
   - Validation: Phone format

5. Service Interested
   - Type: Select dropdown
   - Required: Yes
   - Options:
     * Ocean Freight
     * Air Freight
     * Customs Clearance
     * Warehousing
     * Logistics Consultation
     * Other

6. Shipment Origin
   - Type: Text input
   - Required: No
   - Validation: Text only

7. Shipment Destination
   - Type: Text input
   - Required: No
   - Validation: Text only

8. Message/Details
   - Type: Textarea
   - Required: Yes
   - Validation: Text (6 rows visible)

ASSET DEPENDENCIES
==================

CSS Dependencies:
├── assets/css/main.css (required)
├── assets/css/noscript.css (fallback)
└── All files linked in <head> of each HTML

JavaScript Dependencies:
├── assets/js/jquery.min.js (required)
├── assets/js/jquery.scrolly.min.js (optional - smooth scroll)
├── assets/js/jquery.scrollex.min.js (optional - scroll effects)
├── assets/js/browser.min.js (optional - browser detection)
├── assets/js/breakpoints.min.js (optional - responsive breakpoints)
├── assets/js/util.js (required - utilities)
└── assets/js/main.js (required - main functionality)

Font Dependencies:
├── assets/webfonts/ (included)
└── System fonts as fallback
